# Nbility AI 网关报价单

报价日期：2026-06-13  
适用范围：OpenAI GPT / Codex 相关模型、Anthropic Claude 相关模型  
报价口径：按官方展示模型原价作为基准，平台结算价 = 官方原价数字 × 对应渠道倍率。输入、输出、按次或按秒模型分别按官方对应计价单位计算。

## 一、三层价格关系

- **官方原价**：模型厂商官网公开价格。
- **Nbility 平台原价**：官方原价 × 常规渠道倍率。
- **客户专属价**：达到约定每日额度后，按更低阶梯倍率结算。

### 计价示例

| 场景 | 官方原价 | Nbility 平台原价 | 客户专属价 |
| :--- | :--- | :--- | :--- |
| OpenAI GPT / Codex | $2.50 / 1M | ¥1.00 / 1M（×0.40） | ¥0.75 / 1M（1000额度/天，×0.30） |
| Claude max号池 | $5.00 / 1M | ¥12.00 / 1M（×2.40） | ¥8.00 / 1M（2000额度/天，×1.60） |

### 推荐选择

- **GPT / Codex**：优先使用 gpt pro 号池渠道，适合代码生成、智能体、自动化任务等高频场景。
- **Claude**：优先推荐 claude max 号池，适合高强度 Claude 使用场景；如需对接自有能力，可选择 claude max 号池（可外接）。
- 查看明细表时，先看官方输入价/输出价，再看右侧 Nbility 常规倍率和每日额度阶梯价。

## 四、公式说明

如果某模型官方输入价为 `$2.50 / 1M tokens`：

| 使用渠道 | 对应倍率 | 平台输入结算价 |
| :--- | ---: | ---: |
| gpt pro 号池渠道，常规价 | 0.40 | 2.50 × 0.40 = **1.00 / 1M tokens** |
| gpt pro 号池渠道，500额度/天 | 0.35 | 2.50 × 0.35 = **0.875 / 1M tokens** |
| gpt pro 号池渠道，1000额度/天 | 0.30 | 2.50 × 0.30 = **0.75 / 1M tokens** |

输出价、按次价格或按秒价格同理，均按官方对应价格乘以渠道倍率计算。
