/console 新用户引导卡片：3 种布局方向

目标：新用户第一次进入控制台时，快速知道下一步：充值、创建令牌、拿 Base URL、看文档、去 Playground 验证。

A. 顶部横幅 + 步骤卡片
欢迎使用控制台

完成以下 4 步即可开始调用 API。

1 创建令牌
2 Base URL
3 接入文档
4 Playground

推荐：温和嵌入式引导

放在问候语和统计卡片之间，不打断用户；最适合 dashboard 首页。

B. Checklist 完成度卡片
开始前检查
○ 充值账户余额
○ 创建令牌
○ 复制 Base URL
○ 阅读接入文档
○ 在 Playground 测试
现有统计图表

强任务感：Checklist

清晰但需要判断完成状态；如果没有可靠数据，容易显得“假完成度”。

C. 右侧帮助面板
问候 + 时间筛选
统计图表
快速开始

Token / Base URL / Docs / Playground / Top up

常驻侧栏：帮助入口

不占主流程，但移动端会挤压布局，且对“第一次进入”提醒不够明显。

我建议

采用 A：顶部横幅 + 4~5 个动作卡片。条件上优先只在“新用户状态”展示：无消费记录或无令牌时展示；提供关闭按钮并用 localStorage 记住。
